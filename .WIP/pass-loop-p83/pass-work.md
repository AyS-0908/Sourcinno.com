Not amended (no reset in a shared folder): the working files are put back to LF (content = index) and `version.mjs` re-stamps; the corrected stamps ride in commit 2. Trap for ARCHITECTURE's restore recipe: normalise to LF before `version.mjs`.
- D2 A scratch worktree command `git -C <worktree> config core.autocrlf false` wrote `core.autocrlf=false` into the SHARED `.git/config` (worktrees share config); removed at once (`git config --local --unset core.autocrlf`; effective value back to the system `true`). The rehearsal worktree is created with `git -c core.autocrlf=false worktree add` (LF bytes = committed bytes, stamps match).
- D3 `tools/shell.mjs` is outside the prompt's file list but had to change: after a fixture publish its walk took `assets/data/catalogue.html` for a page (`--check`: « marqueurs invalides (3) », `</head>` introuvable ×3) and a plain `node tools/shell.mjs` would refuse to stamp any page once the owner publishes his first card. Not reported stale when the fragment appears (unlike SANS_USAGE).
