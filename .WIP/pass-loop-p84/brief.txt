THE GATE THAT READS IT - verbatim. These are the rules you are judged by:
- Valid JSON, exactly those five fields, nothing more and nothing less. Malformed = void.
- Backslashes inside JSON strings must be doubled: write \\s, not \s.
- "token" is the code above, character for character. It is single use.
- "verdict" is one of GREEN, FIX, MORE_TESTS. "confidence" is one of high, medium, low.
- "evidence" is a non-empty list; every entry needs a non-empty "cmd" and a "result" of
  exactly PASS or FAIL.
- GREEN needs at least one PASS and tolerates no FAIL. A GREEN over a failing check is refused.
- "opened_fix_section" is true if and only if you appended a fix section this round.
  FIX requires true; GREEN and MORE_TESTS require false.
- Prose - your reasoning, caveats, the fix section itself - goes OUTSIDE the block. Nothing
  you write outside it can void the verdict, and nothing inside it may be prose.
A void review is not a pass: it costs one of the 2 contacts this Pass can afford, and the
Pass never goes green on it.
